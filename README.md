# 🐍 CRUD de Usuários em Python

Projeto desenvolvido durante meus estudos de Python para colocar em prática conceitos de manipulação de arquivos e estruturas de dados.

O sistema funciona pelo terminal e permite cadastrar, listar, buscar, alterar e excluir usuários. Os dados são armazenados em um arquivo `.txt`.

## 🚀 Funcionalidades

- Cadastrar usuários
- Listar usuários cadastrados
- Buscar usuário pelo nome
- Alterar informações de um usuário
- Excluir usuários
- Manter os dados salvos em arquivo

## 📚 Conceitos praticados

Durante o desenvolvimento deste projeto, pratiquei:

- Estruturas condicionais (`if`, `elif`, `else`)
- Laço `while`
- Laço `for`
- Listas
- Dicionários
- Manipulação de strings
- `split()`
- `strip()`
- `lower()`
- Leitura e escrita de arquivos
- `with open()`
- Modos `r`, `a` e `w`

## 💾 Armazenamento dos dados

Os usuários são armazenados no seguinte formato:

```text
Nome | Idade | Cidade
```

## 💻 Como executar

Tenha o Python instalado no computador.

No terminal, execute:

```bash
python principal.py
```
